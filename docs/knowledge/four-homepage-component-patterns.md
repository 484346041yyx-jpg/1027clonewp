## Vapeversse：首页 1069

公开来源：[Vapeversse](https://vapeversse.com/)。正文观察为 10 个顶层板块、15 个 Container；组件包括 1 个嵌套轮播、1 个横幅轮播、3 个商品组件和 1 个 Elementor `posts`，不含共享页脚。

| 职责与节点 | 组合与电脑设置 | 手机设置 / 实际读回 |
| --- | --- | --- |
| 主视觉 `861a2d4` | `wd_nested_carousel → 3 个 Container → wd_image_or_svg`；`slides_per_view.size=1` | 手机每屏字段为空，运行时每屏 1 项；同一图片等比缩小，没有观察到手机专用图 |
| 分类 `4acad5e` | `heading + wd_banner_carousel`；4 个 Repeater 项；`slides_per_view.size=4`；运行时间距 30px | 显式 `slides_per_view_mobile.size=2`；运行时间距 10px；分类标题字号 32px → 24px |
| 商品 `717e811`、`295da67`、`3391132` | `heading + button + wd_products`；`layout=carousel`，`items_per_page=5`，每屏 4；后两组有不同分类绑定 | 每屏手机字段为空；实际每屏 2 项，间距 20px。不能将运行时两项写成手机显式字段 |
| 视频区 `6e53faf` | 父 Container 的视频背景、最小高度 600px、垂直居中；`wd_title + button` | 开启手机播放；仍为 600px 高；主标题 60px → 48px，副文案 24px → 16px。播放配置不等于手机视频播放验收 |
| 长文 `f2ff7b7` | `wd_text_block` 局部 CSS：`max-height:470px; overflow-y:auto; padding-right:10px` | 读回视口高 470px、内容高 2706px；未完成触控滚动到底与恢复测试 |
| 文章 `0a8dfb0` | `posts`，有效每页 6 篇、电脑 3 列 | 有效手机 1 列。来源用了 `posts` 不改变本项目既有 `native-posts + wd_blog` 路线 |

多处正文容器保存 `boxed_width=80%`，还受父级限宽共同影响；不得直接解释为浏览器宽度的 80%。多处板块上外边距为 100px，手机继承后留白仍明显；仅作样本，不形成统一间距。

公开来源：[Prime Vape Outlet](https://primevapeoutlet.com/)。正文为 11 个顶层板块、28 个 Container；包含 2 个嵌套轮播、1 个 Slides、2 个商品组件及 1 个商品 Tabs。

| 职责与节点 | 组合与明确设置 | 手机与条件限定 |
| --- | --- | --- |
| 公告 `a2123f5` | 嵌套轮播内 3 个子容器，各含 `wd_text_block`；每屏 1、`autoplay=yes`、`speed=1500`、隐藏分页 | 手机实际每屏 1；本字段不等于经典 Slides 的动画时长 |
| 主视觉 `be9b5d8` | `slides`，3 个背景 Repeater 项；标题/描述/按钮文案为空，图片自带文案；高度 60vh | 手机高度字段为空，实际继承后约 442px；背景 cover 导致横图明显裁切，不能称为专门适配的手机素材 |
| 商品 `7faa315`、`85a14b9` | 有效 `layout=grid`；各取 8 件，电脑 4 列；首组有分类绑定和 `orderby=rand` | 实际手机 2 列。保存的 `wrap=yes`、`autoplay=yes`、每屏数量等不证明当前网格正在轮播 |
| Tabs `2faab88` | `wd_products_tabs`，3 个标签各有分类绑定；有效网格布局、每组数量 12、电脑 4 列 | 实际手机 2 列；各 Tab 查询仍独立核对 |
| 栏目包装 `593c17f` 等 | 父容器宽度 70%；标题条内边距 20px、字号 32px、白字；渐变 `#D00000 → #FFB347`、90deg | 部分主要容器显式宽度 90%；宽度作用于内层内容，不按最外层 `.e-con` 的全宽反推失效 |
| 双宣传卡 `edc763a` | 背景 Container 最小高度 280px；标题平移 X=60px/Y=120px，按钮 X=-210px/Y=150px | 按钮手机 X 改为 0。该构图依赖坐标，不进入可直接复制的标准配方 |
| 长文 `cac33a4` | 与 Vapeversse 相同的 470px 上限、纵向滚动、右内边距 10px | 内容高 4581px；与本批另一长文合并为同一机制实例，不新增第二条原则 |
| 服务条 `945bd30` | `wd_nested_carousel → Container → image-box`，4 项；图在左、垂直居中，图片宽 12%，标题 16px、说明 14px | 实际每屏 1 项；手机每屏字段为空，不伪写为显式设置 |

“Nicotine Free Vape”等栏目标题不能证明过滤条件；该组未观察到明确分类筛选，保留为业务查询待核对，不据标题推断商品属性。

| 职责与节点 | 电脑实例值 | 手机实例值 / 状态 |
| --- | --- | --- |
| 主视觉 `eaf4996` | `slides` 共 4 项，高度 75vh；父级内容宽度 90% | 手机 25vh、父级 100%；平板另设 43vh |
| 分类标题 `712b048` 等 | `heading` 的标签为 p；紫色 `#6D4EEC`、白字，25px/500，内边距 20px、圆角 16px | 字号 20px，内边距 10px |
| 卡片父级 `9c5546b` 等 | 横向排列；各卡片宽 24% | 允许换行，各卡宽 48%，列间距 12px；实际两列 |
| 代表卡 `9c5d5c0` | `heading → wd_text_block → wd_image_or_svg → button`；内边距 20px、圆角 16px、启用阴影 | 保留原生编辑槽；标题 20px → 16px，说明手机 14px；按钮内边距从上下 20px/左右 40px 变为四边 10px |
| 文章 `43f561e` | `wd_blog`，取 5 篇，每屏 4、间距 30px | 平板每屏 2；手机实际每屏 1、间距 10px |
| 物流 `a5426c8` | 自定义 HTML 内部布局与样式 | 存在 max-width:768px 的纵向排列规则；该 HTML 不作为本项目原生配方或新增 HTML 权限 |
| 长文 `9dfea64` | Container 设置 `wd_collapsible_content_switcher=collapsible-content`，另有 Read more 按钮；读回高度 300px | 读回仍 300px；未验证展开行为，不能与 470px 滚动文本框混为同一机制 |

24 张卡片的结构证明该站采用了分槽编辑，不能单独证明新任务也应拆成同样数量的 Widget。新任务仍先判断完整组件能否覆盖字段、内容顺序与点击范围；不无条件复制来源层级。

### 已隔离的反例

1. 手机五组列表合计 27 个链接的地址为裸 `#`，没有已验证的目标动作；电脑部分同名条目已有实际链接。不能把手机地址复制到目标站。
2. Company Information 手机有 7 项、电脑有 4 项，条目不一致；不能因两分支看起来相似而跳过内容核对。
3. RAZ/Beri/Geek Bar 的 Tab 名称不同，但 `taxonomies` 与 `include` 均为空；两个普通商品区也不能仅凭“New Arrivals / E-Liquids”标题确认筛选。需要的业务查询在新任务中重新核实。
4. 编辑器中设备隐藏区域可能仍半透明占位；与共享模板在当前预览的真实隐藏结果区分，不把编辑器提示或隐藏副本复制为前台内容。
