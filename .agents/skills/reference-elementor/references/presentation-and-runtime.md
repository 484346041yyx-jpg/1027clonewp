# 控件、响应式与执行

浏览器设备事实与 DOM 几何必须在截图前的同一次采样冻结。全页截图之后的事实另列 `afterScreenshotFacts`，不得覆盖原事实；若截图导致 clientWidth 等布局指标改变，像素比较只能作为诊断，不能授予视觉保真通过。

验收前用 `stylesheet-readiness.ts` 等待当前启用、匹配 media 的真实样式表完成。`DOMContentLoaded`、字体就绪或稳定几何均不能单独证明样式已加载；未样式化页面也可能尺寸稳定。明确 CSS HTTP/网络/link 错误最多触发一次同 URL 重载，原失败与恢复分开留证；永久错误保存具体缺口并中止该次画面采样。没有适用外链 CSS 的合法页面记录为不适用。此步骤只证明资源就绪，不授予视觉保真通过。

续跑优先读取当前 owned run 的 `latest-revision.json` 和其真实 final snapshot；根目录旧报告作为不可变历史保留。任何目标写入仍要求新读取的当前哈希等于明确的基线，不用“最新目录名”代替哈希证明。

## 先取得完整表现证据

对实际交互边界识别轨道、项目、导航组、计数器、分页、播放/暂停及其定位参照。控件可能在父容器、兄弟节点或门户中；用 aria-controls、真实组件关联、共同职责区域和实际点击作用确认归属。未关联的相邻按钮不能自动归入轮播。采集伪元素、SVG、图标字体的绘制来源，分开记录点击框和可见图形。

逐视口记录控件类型、显隐、相对位置、排列、基线、尺寸、颜色、边框、圆角、间距及普通/悬停/禁用/选中状态。分数分页必须由真实轮播驱动；目标商品分页总数由真实查询及分组规则决定。不能用静态计数器、组件默认圆点或统一箭头位置替代源证据。源站未观察的状态标明缺口。

内部背景区域和按钮的归属也要冻结。背景归属于祖先容器，不能凭锚点透明背景判断它在区域内还是外。内部文字、按钮、轨道和控制组的可见性、相对位置、换行、遮挡与裁剪属于验收内容，根块宽度和无页面溢出不能替代它们。

## 响应式单独建模

从每个有证据的尺寸提取显隐、重排、列数、换行、控件停靠点和媒体版本，不能从桌面统一缩小。检查 picture/source 的 media/srcset/sizes、实际 currentSrc、DPR、图像比例与 object-fit/position。手机横图和桌面竖图须绑定到可编辑的响应式原生媒体，或原生图片的响应式显隐组合；只设置 width:100% 不代表完成换图。

商品动态替换应使用内容可变的卡片约束，保留图像比例、列数、名称/评级/价格顺序、行数策略和控制位置。不要复制整个源块高度掩盖不同商品长度。字体回退须检查换行和按钮尺寸影响；缺失字体不能让排版变化自动通过。

真实前端、Elementor 预览模式、正常编辑模式分开留证。编辑器可显示手机隐藏元素的淡色占位；占位不等于真实前端显示，但仍需证明真实预览正常。记录 iframe 的实际 innerWidth/clientWidth、缩放和命中断点。覆盖代表性窄/宽手机及发现断点的两侧；宽度列表按实际 CSS 与组件证据生成，不能只测一个手机尺寸。触摸/hover 行为须标注设备模拟条件。

编译前拒绝 NaN、Infinity 和无效数字声明。发现源证据缺失、控件能力不足或关系不确定时，保留命名缺口，不编造表现或扩大容差。

## 能力预检与真实验收

完整草稿写入前，核对实际注册组件是否能同时表达查询、卡片、控件和响应式媒体。优先已证明的原生设置，其次所属组件内受限 CSS。CSS 无法把未绑定的静态文字变为动态分页。不能为解决缺口擅自安装插件、启用全局功能、注入脚本或退回 HTML 外壳。

使用当前类型定义中的 presentation 契约和真实浏览器探针绑定关键子区域。来源声明、实际测量、未观察三者分开；没有子区域证据的旧任务只能报告未验证，不能沿用“结构通过”宣称视觉精准。

局部视觉比较必须在相同有效宽度、滚动/轮播状态、缩放和已稳定绘制条件下进行。不同目标商品文字和媒体内容可排除内容相等比较，卡片边界、布局、文字角色、箭头和分页不能一起排除。差异图辅助诊断；原生编辑和真实交互证明仍必须完成。

## 减少重复执行

同尺寸优先复用已载入页面，顺序完成普通状态、交互、恢复和测量。各尺寸只读观察可有限并发；同草稿写入、编辑保存和恢复始终串行。保留实际就绪条件和有界等待，不因提速跳过加载、真实保存或回读。

按输入、素材、组件环境和文档哈希复用结果。续跑必须核对当前 run/page 和远端完整哈希；未知变化属于并发编辑，不能覆盖。只重做受影响部分，再做最终整页回归。旧编辑证明保留原始哈希及适用范围，不能伪装为新文档的测试。

控件能力缓存按目标环境/版本失效，静态素材按实际字节哈希复用；新 URL 不继承旧品牌、布局或源证据。凭据和浏览器验证状态不落盘。记录各阶段时耗、重试、缓存命中与请求数，依据实际数据评估速度，不承诺未经测量的倍数。

分页呈现须使用当前原生组件实际支持的模式；按当前 native44 交互检查读取真实逻辑页、分页和恢复状态。已移除的旧分数分页适配器不再作为当前能力。

长页面超过浏览器单次读取限制时，使用独立 DOM 候选清单与完整的逐块包，再由 `mergeScopedSourcePackets` 校验合并。每个候选必须有唯一职责，每个块只出现一次，所有根选择器均参与采集；缺包和预算截断不能消除。浏览器返回前将数据做 JSON round-trip，避免共享对象被传输层误记为 `[Circular]`。遇到损坏数据重新观察，不能从目标布局补造源事实。

旧证据由 `relocateReferenceEvidence` 按类型化路径递归迁移，核对实际字节、原始/新路径、哈希、URL和采集时间。历史缺失的场景清单仍须重新观察。切换尺寸后等待实际布局及轮播卡宽完成重排，分别比较前后几何；固定等待或单次快照不等于稳定证明。已测且被 CSS 隐藏的控件是该尺寸下的观察结果，不自动算采集失败。

控件位置修正使用 `planControlAlignment`，输入真实 source/target、实际 CSS containing block 的 padding-box 和生效的 authored anchor。控件的 offsetParent 可能是轨道容器，也可能是小工具外框；同一组件的箭头和兄弟分页须分别绑定。该函数只提出有边界的平移；尺寸、缩放、所有权、锚点或来源不明确时拒绝，修正后仍须实际重测。

按已保存的原生样式做后续修订，可显式复用同一 run 已实际通过的编辑回执。`loadReusableEditorCheckpoint` 要求原始回执的恢复哈希与当前基线完全相等，且文字、图片、样式、轮播和商品查询的修改/保存/前端/恢复都已通过；同时证明树、静态内容、媒体、查询与源契约未变。保留原文件 SHA、原时间及原文档哈希，明确本轮没有重做这些 UI 测试。三端画面、数据、控件和交互必须重新采集。失败、部分成功或跨 run 回执不可复用。

重复 DOM 不等于商品列表：按实测父子关系区分查询列表、卡内数据槽、静态布局重复及未知结构。卡内槽必须对应同卡实测区域和同原生查询所有者，不要求它伪装为整条轨道，也不因此删除独立场景事实。源端确实零尺寸隐藏、目标也隐藏且原生设置保留精确原文的响应式副本可单列 `source-inactive`；不可把它计作已绘制文字匹配，更不能据此免除缺失绑定或未观测的源文字。

完整来源和素材校验通过后，已授权的复核草稿可以携带明确的未解决表现问题供真实浏览器和编辑器迭代。此时写入 `review-draft-intent.json`，保留原审核失败/待复核状态；缺失、陈旧、哈希不符的独立来源不允许此路径。复核草稿不获得保真通过，也不能发布。

响应式静态媒体必须按同一个已观察 picture/职责节点的实际来源选择。通过 picture/source 的 URL 关系及字节哈希确认桌面、平板、手机是否需要不同资源，不能仅凭文件名猜归属。优先使用实际注册的响应式原生背景媒体；原生图片控件没有对应媒体版本设置时，采用同一职责内的原生图片与断点显隐组合，每个版本均可单独编辑。将实际挂载的每个资源列入本块素材和哈希清单，并在前端检查实际生效的 URL/字节与断点；记录素材不能替代真实挂载。

商品换成目标数据时，源名称/价格的短字形宽度不能成为目标内容的固定宽度。保留源卡片和角色分配框、内边距、顺序、字体、行数及溢出规则；只有独立测得的同卡片分配框才能使用 allocation 比较，不能将期望框回填成实测值。缺席角色须有完整卡片证据，源 New/促销/评级等商品事实另走目标数据替换，不把源商品承诺贴到目标商品上。

同名视口不等于相同内容宽度：按来源实际 innerWidth/clientWidth 判断滚动条是否占位，自动验证浏览器应采用相符的浏览器滚动条环境，并保留测量回执；不要注入页面 CSS 或改素材来消除验证浏览器默认隐藏滚动条造成的宽度误差。目标的实际环境仍需逐尺寸回读核对，未知触摸/DPR 事实保持未知。
# 续跑时的身份与资源校验

来源事实、组件映射和需求覆盖使用当前 `src/replica-v2/component-plan.ts` 与 `src/native44/source-bindings.ts` 验证。重复文字须按节点、归属及视口区分，规划提案不修改冻结合同或授予通过。

原生草稿预览的样式就绪检查须携带实际拥有的文档 ID，并在实际 CSSOM 中确认该文档作用域存在。已有公共样式全都加载成功，不能证明页面自己的样式声明存在；缺失该作用域须保留失败样本，最多一次对完全相同 URL 的重载，之后仍缺失则停止该次测量。不得根据预期尺寸决定是否重载。

样式续跑的精确差异比较先区分显式作者输入与序列化补入的注册默认值。只可保留同一原生树中、作者未输入、由真实注册简单条件在修改前后均证明未激活的已有默认值；保留项写入回执并继续完整回读比较。活动控件、查询、未知条件、人类输入和身份变化仍按真实变化处理，不能以提速为由略过。
