# 证据到原生组件

## 可执行工作流

`reference` 在本次源视口保存 `sourceScene` 原始事实与 `sceneInventory`，独立列举区块、内容框、重复卡片模板、控制组和控制器。清单来自浏览器采集，不能从生成后的 `program.json` 反推。普通状态不能证明悬停、切换或自动播放；身份、归属或状态未知时保留 gap。

按真实源选择器冻结 `BlockContract.sourceSceneBindings`，包括视口、源事实 ID、源区块、要求种类与目标原生 key。控件还须与 `presentationDetails` 及原生 `presentationBindings` 对应；数据字段的替换不豁免其展示槽位。框架类名只是辅助证据，不能把不认识的轮播库当静态内容。

在编写完整原生程序前，用已保存且版本匹配的真实注册控件报告执行：

```powershell
npm run design:plan -- "references/<jobId>" "<当前已验证的原生能力报告路径>"
```

这是内部规划步骤，路径由系统已有证据取得，不要求用户提供额外输入。离线报告只证明注册控制的表达能力；不能声称它已通过浏览器验证。没有可信报告时，记录能力未证，不猜组件功能。`create` 在完整本地检查后重新发现实时控件，按源要求与已选组件的完整功能组合检查，失败时不创建草稿或导入媒体。

`design:check` 检查独立源清单覆盖；缺少旧清单返回 `needs-review`，观察到但遗漏的事实返回失败。`create` 对未通过源覆盖的输入在加载目标凭据前停止。不能靠删清单、放宽容差、增加 deviation 或把缺口改成 warning 继续宣称完成。

## 三份相互关联的要求

- 数据：目标 WooCommerce 查询、真实商品 ID/顺序，以及明确替换的字段。不得把源促销事实分配给自己的商品。
- 呈现：区块背景和内容框、父子/兄弟关系、卡片框和图片/名称/评级/价格槽、显隐、字体、间距、边框、裁切。
- 行为：每个触发器、控制对象、操作前后状态、反向/重复操作、分页同步和存在时的播放/暂停。总页数根据目标商品及实际分组重算。

选组件时应匹配整套要求；支持商品查询不代表支持分数分页，自动播放开关也不代表用户可点击的播放/暂停按钮。适配器必须声明原生类与实际控制项，不能仅凭名称或 label。能力表达不足时应补充受验证的原生适配方案或明确停止；CSS 和静态文字不能补出动态行为。

能力发现必须说明枚举范围。只检查程序已选择的控件，不能推出整个目标站没有替代组件；需要判断是否存在替代组件时，先只读枚举实际注册的全部类型，再检查候选控件的完整控制组合。候选组件自己的暂停按钮不能冒充另一个轮播的控制器，须证明真实控制对象、前端事件和保存回读关系。字体族名称可选也不能证明已加载了相同字体文件或实际绘制字形。

## 实际比较和修复

验收单位是组件、视口与状态。小控件几何使用独立严格容差，贴边、填满、对齐、归属和控件数量是关系要求；整块的宽高容差不能豁免这些关系。保存源商品的可见卡片模板证据，避免把离屏或轮播克隆样本误当模板。

正式验收运行局部截图比较，保持字体、加载、设备条件和交互状态可比。动态商品只排除已授权字段的内容像素，不遮整个卡片、轨道或控件；仍验其字体、槽位、图框和布局。遮罩不确定或状态无法稳定时报告未验证，不强行生成相似度通过。

截图必须保留实际测量时的 CSS 视口和滚动条宽度。Chromium 的整页 beyond-viewport 截图可能移除滚动条并重新布局；即使请求尺寸相同，也不能把重排后的像素与此前 DOM 几何混作同帧证据。使用真实视口截图时记录实际滚动位置、分段范围、固定或 sticky 元素、布局前后事实和限制，恢复原滚动位置；未证明的拼接连续性、动画状态和旧截图不能静默算作通过。不可通过隐藏整页溢出或改变视口来消除误差。

响应式宽度来自真实源视口和已发现断点探测，自动进入目标验收。显隐、重排、素材版本和图片 fit 分别冻结；手机前台与编辑器画布分开验证，记录实际 iframe 宽度。编辑器隐藏占位影响其他块的布局时仍是编辑可用性问题。

差异定位到源事实 ID、原生 key、对应控制/布局设置与受影响范围。局部修复重测所属组件与依赖它的相邻布局，父宽度/断点/字体改变时扩大范围。只读页面可复用；保存和恢复始终串行，并核对当前文档完整哈希。

## 完成条件与速度

分别报告源证据、视觉、行为、响应式、商品数据和原生编辑。只读前台验证没有编辑证明时，编辑轴是 `unchecked`；`frontendPassed` 不等于整项任务完成。缺控件、已知能力缺口、待补证或未执行比较均不能成为完成结论。

缓存使用实际输入字节、原生环境版本、设备、目标查询与文档哈希失效。允许复用相同字节的图片解码元数据，不省略素材重新哈希。保留阶段时耗和请求统计；提速效果用同任务冷启动和续跑实测，不用少一次请求代替端到端结论。

跨站测试按布局与行为特征覆盖，并保留未参与适配开发的网站。回归应主动删除控件、改变边框或断点，证明检查能拒绝这些错误；fixture 和编译成功不能替代真实源站、前台与编辑器证据。
